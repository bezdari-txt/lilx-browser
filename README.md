<h1 align="center">lilx</h1>

<p align="center">
  minimal and privacy-focused browser made with python + pyside6/qtwebengine.
</p>

## features

- tabs, history, downloads and bookmarks
- custom `lilx://` pages
- lilblock ad blocker
- per-site privacy controls
- manifest v3 extensions
- english / russian
- factory reset
- macos, linux and windows support

## run

```bash
git clone https://github.com/bezdari-txt/lilx-browser.git
cd lilx-browser

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
python -m lilx
```

windows:

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -m lilx
```

## status

lilx is still in early development. things can break or change.
